1. **0:00 Problem (15 s)**: portfolios mix self-claims, friend endorsements and real credentials into one "verified" tick.

   Show the non-holder error with a random address.

5. **1:20 Attest (30 s)**: copy request link → second Agent ID holder opens it → relationship + comment → sign. Show that
   self-attestation and duplicate attempts are blocked by the simulation. Profile now shows **Peer attested · 1**.
6. **1:50 Credential (20 s)**: admin approves an issuer → issuer issues "Finalist" → **Approved issuer credential**.
7. **2:10 Verify (25 s)**: paste the attestation tx hash into /verify: decoded event → "Check current state" →
   integrity vs truth panels. Revoke the attestation and show it stays in history as revoked.
8. **2:35 Close (10 s)**: contracts on BscScan, open-source repo, limitations line.
